First-time setup

Run once in Terminal from the PhotoGit folder. doctor checks the setup.

npm run photogit -- init "/path/to/project"
npm run helper -- --approve-root "/path/to/project"
npm run photogit -- doctor "/path/to/project"

Saved versions include the full PSD. Opening a version creates a separate copy. Combining branches doesn’t blend layers; review the result in Photoshop.

Each saved version is a Git commit; /commit is an alias for /save.
