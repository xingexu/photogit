Helper setup instructions

From the PhotoGit source folder in Terminal, initialize your project and start its helper. Keep the helper running, then choose the project folder here.

npm run photogit -- init "/path/to/project"
npm run helper -- --approve-root "/path/to/project"

Open PhotoGit from Photoshop’s Plugins → PhotoGit menu. Drag its native panel tab beside the left toolbar. Release when Photoshop shows a docking highlight. Panel placement is controlled by Photoshop.

Reconnect the helper

In the PhotoGit source folder, run: npm run helper -- --approve-root "/path/to/project". Then reconnect.

Command directory

Quick access

Search or choose a command. Press / outside a text field, or Ctrl+K (⌘K on a Mac), while the panel has focus. If Photoshop intercepts a shortcut, use Commands above. Enter submits the version-message field.

Setup in Terminal

Run these from the PhotoGit source folder, not in the command palette. Replace the example with your project’s full path.

npm run photogit -- init "/path/to/project"
npm run helper -- --approve-root "/path/to/project"
npm run photogit -- doctor "/path/to/project"

A saved version is a Git commit. /commit is an alias for /save. Earlier PSDs open separately; adopt a copy deliberately before saving it into a project. Merge uses ordinary Git, not layer blending. Sampled appearance comparisons can miss tiny edits.
