# PhotoGit landing page

Serve this directory with `python3 -m http.server 3000 --directory site` from the repository root.

On load, the canvas settles into the workspace, light sweeps across the image, and the Layers and Swatches panels drift into place. Hover over the workspace with a mouse to tilt it. The artwork is a local WebP.

Click or tap the PhotoGit label, or activate it with Enter or Space, to reveal the optional petal burst and bird reaction. Escape dismisses it. The footer sound toggle remembers your preference. Reduced-motion settings disable the entrance animations, tilt, and burst.

The bird chirp plays after a user gesture and respects browser and device settings.

For Vercel Git imports, set Root Directory to `site`, framework to Other, no build command, and output directory to `.`.
