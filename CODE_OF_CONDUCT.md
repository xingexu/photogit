# Code of conduct

Treat contributors and users respectfully. Critique code and decisions without harassment, threats, discrimination, or personal attacks. Do not publish another person's private information, credentials, or artwork.

Use issues and pull requests for constructive, relevant discussion. Maintainers may edit or remove abusive content and restrict participation when needed to protect the project community.

Report conduct concerns privately to the maintainer at [xxu767@uwo.ca](mailto:xxu767@uwo.ca), the contact published on [xinge.ca](https://xinge.ca/). Include relevant links and only the personal information needed to understand the concern. No guaranteed response time is offered.
