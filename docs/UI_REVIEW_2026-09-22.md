# Panel readability review — September 22, 2026

The panel retains its blue glass appearance with denser reading surfaces, a
quieter wallpaper, less top sheen, and a stable header background. Both native
and simulated entrypoints initially used asset version 109. The subsequent
drawing/history update advances the shared stamp; see
[Drawing detection and visual version history](DRAWING_HISTORY_2026-09-22.md).

The change addresses light text washing out over the brightest wallpaper areas,
particularly in the lighter theme. A conservative sRGB alpha-compositing check
uses a white wallpaper pixel, the backdrop tint, the card fill and maximum top
sheen. Muted-text contrast on this surface changes as follows:

| Theme | Before | After |
| --- | ---: | ---: |
| Dark | 4.78:1 | 8.95:1 |
| Light | 1.87:1 | 6.15:1 |

These are calculated card-surface ratios, not a certification of all controls or
native Photoshop rendering.
