# Reference layout and automatic updates

The wide Photoshop workspace now keeps its header, navigation and Git actions visible. History and version details scroll independently inside the glass surface. Short or docked panels retain the compact scrolling layout. The browser demo uses the same panel markup and styles.

Adobe UXP Developer Tools Watch mode is enabled for the local PhotoGit development plugin. It reloads source changes while Developer Tools and Photoshop are running. Build 117 was observed in Photoshop after changing the asset stamp without clicking Reload; the previously selected saved version was restored.

Project-scoped local preferences preserve the version-message draft, history search and selected preview across reloads. A quiet history read runs every ten seconds, skips active commands and scans, and redraws only when versions change. Photoshop drawing detection continues through notifications and history-state observation. Commands that interrupt a pending scan now resume it afterward; explicit scan cancellation still shows the paused state.

Verification covered dark and light themes at 1600×1000, 1100×780, 720×780, 420×800 and 230×400. Wide layouts kept both footer controls and shortcut text in view with no horizontal overflow. Version details scrolled independently of the footer. Native Photoshop reported a 1100×780 panel, build 117, a ready selected preview, and successful automatic scanning.
